# Аринастройс — бот-редактор канала

Принимает материал со стройки в личку, монтирует вертикальный ролик, пишет текст
и публикует в канал по твоей кнопке. По пн/ср/пт придумывает и выпускает посты сам.

Работает на GitHub Actions — бесплатно, компьютер держать включённым не нужно.

```
ты в личке боту          GitHub Actions (каждые 10 минут)        канал
──────────────────       ──────────────────────────────────      ──────────
фото + видео       →     забирает почту
подпись с деталями       скачивает, режет лучшие куски
                         9:16, музыка, титры, до/после
                         пишет текст и хэштеги
                         присылает превью с кнопками       →     ✅ жмёшь — вышло

                         вс/вт/чт 19:00 придумывает пост
                         присылает на утверждение          →     пн/ср/пт 10:30 МСК
```

## Настройка (один раз)

### 1. Репозиторий
`github.com` → New repository → имя `arinastroys-bot` → **Public** → Create.

Публичный — принципиально: для публичных репозиториев минуты Actions бесплатны
и без лимита. Токены при этом лежат в секретах и в коде не видны.

### 2. Загрузить файлы
Add file → Upload files → перетащить **содержимое** папки целиком, сохраняя пути
(`.github/workflows/…`, `scripts/…`, `assets/…`, `state/…`, `requirements.txt`).

### 3. Разрешить Actions писать в репозиторий
Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

Без этого бот не сможет сохранять состояние между запусками и будет каждый раз
забывать, что уже сделал.

### 4. Секреты
Settings → Secrets and variables → Actions → вкладка **Secrets** → New repository secret:

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `OWNER_ID` | твой Telegram id — узнать у @userinfobot |
| `CHANNEL_ID` | `@arinastroys` или `-100…` |
| `ANTHROPIC_API_KEY` | ключ с console.anthropic.com |

### 5. Переменные (необязательно)
Та же страница, вкладка **Variables**:

| Имя | По умолчанию |
|---|---|
| `POST_DAYS` | `mon,wed,fri` |
| `POST_TIME` | `10:30` |
| `AUTO_PUBLISH` | `false` — публиковать автопосты без твоего «ок» |
| `BRAND_CHANNEL` | `@arinastroys` |
| `CONTACT_USERNAME` | `@ArturAkopo` |

### 6. Бот в канале
Канал → Администраторы → добавить бота → включить **Публикация сообщений**.

### 7. Проверка
Actions → «Проверка лички и монтаж» → Run workflow.
Затем напиши боту `/health` — он проверит ключи, права в канале, шрифты и музыку.

## Что доложить руками

```bash
bash scripts/fetch_assets.sh
```
Скачает шрифты Oswald и Golos Text в `assets/fonts/`.

Сверх этого:
- `assets/brand/logo.png` — логотип на прозрачном фоне, белый, высота от 300 px.
  Без него на титрах будет текстовое `ARINASTROYS`.
- `assets/music/*.mp3` — 3–5 треков без авторских прав (Pixabay Music, Uppbeat).
  Без них ролики будут немыми.

Эти файлы тоже заливаются в репозиторий через Add file → Upload files.

## Как пользоваться

Кидай фото и видео в личку боту. Он проверяет почту каждые 10 минут, поэтому
пост приходит **в течение 10–20 минут**, а не мгновенно. Хочешь сразу — `/go`.

Вместе с материалом напиши подписью к первому файлу: город, помещение, стадия
и всё, что стоит упомянуть. Бот не выдумывает деталей, которых ты не дал —
если написать нечего, текст выйдет общим.

Кнопки под превью: Опубликовать · В очередь · Правка текста · Другой текст ·
Перемонтировать · Удалить.

Команды: `/go` `/queue` `/drop 5` `/now` `/health` `/help`

## Важные ограничения

**Файлы до 20 МБ.** Облачный Telegram не отдаёт боту больше. Поэтому видео
присылай **обычным видео, не «файлом»** — Telegram сожмёт, и ролик до ~40 секунд
уложится в лимит. Правило «отправлять файлом без сжатия» из памятки по съёмке
остаётся в силе для архива и Instagram, но не для бота.

**Расписание Actions опаздывает.** В часы пик запуск сдвигается на 5–15 минут.
Для утреннего поста это незаметно, но точности до минуты не будет.

**Если 60 дней не трогать репозиторий**, GitHub выключает cron. Бот сам коммитит
состояние при каждом запуске, так что это не грозит.

**Ключ Anthropic платный.** При этих объёмах — единицы долларов в месяц.
Без ключа бот всё равно смонтирует ролик, но подписью поставит твой же
комментарий вместо написанного текста.

## Что править под себя

**Голос бренда** — `scripts/brand.py`, константа `BRAND`. Там же красные линии:
не обещать бригады по всей России, не выдумывать цены и гарантии. Когда клиент
ответит про вилку за м² и срок гарантии — впиши туда, тексты станут конкретнее.

**Рубрики и доли** — `RUBRIC_WEIGHTS` там же.

**Оформление картинок** — `scripts/photo.py`. **Монтаж** — `scripts/video.py`:
длина ролика, длина куска, переходы, музыка. Логика отбора живого куска —
функция `pick_window`.

**Расписание** — строки `cron` в `.github/workflows/*.yml`. Время в UTC,
МСК = UTC+3.

## Проверить без Telegram

```bash
cd scripts
python3 selftest.py /путь/к/папке/с/материалом
```
Прогонит разбор пачки, монтаж, сборку подписи и публикацию на заглушках.

## Когда что-то не так

| Симптом | Причина |
|---|---|
| бот молчит | Actions → посмотри, падает ли последний запуск |
| «файл не скачался» | видео тяжелее 20 МБ — пришли обычным видео, не файлом |
| текст = твоя же подпись | не задан или кончился `ANTHROPIC_API_KEY` |
| бот забывает посты | не включены Read and write permissions (шаг 3) |
| ролик немой | нет файлов в `assets/music/` |
| не публикует в канал | нет права «Публикация сообщений» |
